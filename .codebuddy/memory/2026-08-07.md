### 问题2: 路由 path 与 defaultHomePath 不匹配导致404
**根因**: 后端返回 Workbench 菜单 `url: "workbench"` (相对路径)，`genMenuTree` 处理后 `path = "/workbench"`。但前端 `preferences.defaultHomePath = "/dashboard/workbench"`，路由不匹配 → 404。

**修复**: 在 `api/core/menu.ts` 的 `genMenuTree` 中添加路径修正逻辑：
- 当 `url` 是相对路径(无 `/` 前缀) 且 `component` 是绝对路径包含目录时
- 使用 component 目录作为路由 path
- 如 `component="/dashboard/workbench/index"` → `path="/dashboard/workbench"`

修改文件: `apps/web-antd/src/api/core/menu.ts`
