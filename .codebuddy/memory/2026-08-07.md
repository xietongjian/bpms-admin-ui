## Bug 修复: formDefinition 切换自定义/业务表单时表格无数据显示

### 根因
vxe-table adapter 配置了 `proxyConfig.response: { result: 'rows', total: 'total' }`，即 vxe-table 从响应中查找 `rows` 字段获取数据行。但 `index.vue` 的 `query` 函数返回 `{ items: [...], total: N }`，字段名用了 `items` 而非 `rows`，vxe-table 按配置找 `rows` 字段找不到，表格为空。

### 修复
- `formDefinition/index.vue` query 函数：`pageList`/`bizPageList` 本身返回的就是 `{ rows, total }` 格式（被 `responseReturn: 'data'` 自动解包），直接返回 API 结果即可，无需再做 `{ items, total }` 包装。与 `app/index.vue` 保持一致模式。

## Bug 修复: formDefinition expand_content 展开表格无高度 + 子表分页无响应

### 根因1: 展开表无高度
子表 vxe-grid 在展开行中未设置 `height`，表格高度塌缩为 0。

## Bug 修复: formDefinition 子表编辑表单弹窗未最大化

### 根因
`FormInfoDefDesignerModal.vue` 模板使用 `:defaultFullscreen="true"` 但 `ModalState` 中全屏状态的 key 是 `fullscreen`（`modal-api.ts:52`），`defaultFullscreen` 不是合法 state key，`usePriorityValues` 无法识别，弹窗从未进入最大化。

### 修复
- 移除模板中无效的 `:defaultFullscreen="true"`
- 在 `useVbenModal` 配置中设置 `fullscreen: true`，写入 `ModalState.store` 初始状态
- 子表编辑表单打开时自动全屏

## 重构: FormInfoDefDesignerModal header 替换 BasicModal 默认头部

### 改动
- `FormInfoDefDesignerModal.vue` 将 `form-def-designer-header` div 从默认内容区移到 `<template #title>` 插槽
- BasicModal 的 `#title` 插槽直接替换 Modal 默认标题栏，header 中的表单名称、版本号、状态Tag、保存/关闭按钮均显示在 Modal 标题栏位置
- 样式简化：`form-def-designer-header` 不再嵌套在 `.form-def-designer-modal` 内，独立作用域，添加 `width: 100%`
